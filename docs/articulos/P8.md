# P8 — Cómo sobrevive el régimen cribado en aulas masivas o sin Git

> Capa 2 del cribado del protocolo: el porqué. Para el cómo aplicarlo, ver [`RESUMEN-OPERATIVO.md`](../../RESUMEN-OPERATIVO.md). Para el debate completo, ver [discussions#1, punto P8](https://github.com/mmasias/pyAI-edu/discussions/1).

## ¿Qué se decidió?

Los mecanismos de verificación del cribado (guion de defensa oral, muestreo por señal) surgieron en el contexto del grado de Ingeniería Informática: cohort pequeño (~50 alumnos), infraestructura Git, trackers de seguimiento. Fuera de ese contexto — asignaturas de 100-200 alumnos, sin repositorio, sin histórico individual del alumno — el coste de verificación explota y el muestreo por señal no tiene dónde apoyarse.

La recomendación inicial era **dos niveles del régimen**: uno completo (con muestreo, defensa oral, histórico) para asignaturas con infraestructura; uno mínimo (declaración + verificación reactiva bajo indicio fuerte) para asignaturas masivas o sin infraestructura.

Se descartó esa fragmentación. La decisión final: **un solo régimen con verificación reactiva bajo indicio legítimo** (definido en P10), apoyado en **trazabilidad pasiva universal de base** a coste cero vía ecosistema Google (Docs, Sheets, Presentaciones, Colab).

## ¿Por qué?

La trazabilidad pasiva no requiere Git. Google Docs guarda cada revisión con timestamp de servidor, no editable por el alumno, sin que nadie tenga que configurar nada. La única regla operativa necesaria: _la entrega de régimen B/D se redacta en un documento compartido con el profesor desde el primer día, nunca se pega un documento final_. Coste cero para el alumno, un enlace compartido para el profesor.

Eso genera el histórico del alumno que P2 necesitaba para el muestreo por señal, sin infraestructura nueva. Y el enlace de chat compartido (cuando la plataforma lo permite) funciona como evidencia bajo indicio, no como trazabilidad de base — el alumno controla qué conversación comparte.

## ¿Para qué?

Para evitar la desigualdad institucional que la fragmentación asumía: alumnos de asignaturas masivas con régimen más laxo, alumnos de asignaturas pequeñas con régimen completo. Con la solución adoptada, todos los alumnos están bajo el mismo régimen; la verificación reactiva depende del indicio, no del contexto.

Y para evitar también el fracaso del V9 en aulas masivas: un régimen único que el profesorado no puede cumplir termina improvisando, que es justo lo que el cribado quería evitar.

## Relacionado
